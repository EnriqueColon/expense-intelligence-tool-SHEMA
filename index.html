Retrain the model using all labeled transactions saved in the database.

When should you retrain?

  • 50+ new transactions have been saved since the last retrain — more data means a better model.
  • You are manually correcting more than ~10–15% of classifications — this is the clearest sign the model is drifting.
  • You have added new expense types or vendors the model has not seen before.
  • As a backstop: every 6 months if none of the above have applied.
